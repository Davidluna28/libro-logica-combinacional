# 📚 Glosario

| Término | Definición |
|---|---|
| **Bit** | Unidad mínima de información: 0 o 1. |
| **BCD** | Decimal codificado en binario; cada dígito decimal usa 4 bits. |
| **Gray** | Código en el que dos valores consecutivos difieren en un solo bit. |
| **ASCII** | Código estándar de 7 bits para caracteres. |
| **Complemento a dos** | Representación de enteros con signo: invertir bits y sumar 1. |
| **Compuerta lógica** | Circuito que realiza una operación booleana básica. |
| **Tabla de verdad** | Lista de todas las combinaciones de entrada con su salida. |
| **Minitérmino** | Producto de todas las variables que vale 1 en una sola fila. |
| **Maxitérmino** | Suma de todas las variables que vale 0 en una sola fila. |
| **SOP** | Suma de productos. |
| **POS** | Producto de sumas. |
| **Karnaugh (mapa)** | Representación geométrica de la tabla de verdad para simplificar. |
| **Condición indiferente** | Combinación cuya salida no importa; se marca con X. |
| **Universalidad** | Propiedad de NAND y NOR de poder construir cualquier función. |
| **Semisumador** | Suma dos bits; genera suma y acarreo. |
| **Sumador completo** | Suma tres bits (incluye acarreo de entrada). |
| **Acarreo (carry)** | Bit que se transfiere a la siguiente posición en una suma. |
| **Retardo de propagación** | Tiempo que tarda un cambio en la entrada en reflejarse en la salida. |
| **ALU** | Unidad aritmético-lógica del procesador. |
| **74LS** | Familia de circuitos integrados TTL de baja potencia Schottky. |
